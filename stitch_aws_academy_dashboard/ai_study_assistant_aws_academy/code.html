What is the difference between a Security Group and a Network ACL?

smart_toy
Study Buddy

Great question. Both are essential for VPC security, but they operate at different levels. Here is a quick comparison:

Feature Security Group (SG) Network ACL (NACL)
Scope Instance level (ENI) Subnet level
State Stateful (Return traffic allowed automatically) Stateless (Return traffic must be explicitly allowed)
Rules Allow rules only Allow and Deny rules
Default Denies all inbound, allows all outbound Allows all inbound and outbound (Default NACL)
