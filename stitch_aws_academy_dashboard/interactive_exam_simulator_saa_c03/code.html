Domain 1: Design Resilient Architectures

A company needs to implement a storage solution for backup files that are accessed infrequently but must be available immediately when needed. Which S3 storage class is the most cost-effective?

check_circle

Correct Answer: B

Amazon S3 Standard-Infrequent Access (S3 Standard-IA) is the correct choice because it is designed for data that is accessed less frequently, but requires rapid access when needed. It offers the high durability, high throughput, and low latency of S3 Standard, with a low per GB storage price and per GB retrieval fee.

While S3 Glacier Instant Retrieval also provides rapid access (milliseconds) for infrequently accessed data, it is optimized for data accessed rarely (once a quarter). If the backup files might be needed more often than rarely but still infrequently, S3 Standard-IA is typically the more cost-effective balance between storage and retrieval costs, especially considering minimum storage duration requirements.

Storage Class Retrieval Time Min Storage Duration
S3 Standard Milliseconds None
S3 Standard-IA Milliseconds 30 days
S3 Glacier Instant Retrieval Milliseconds 90 days
